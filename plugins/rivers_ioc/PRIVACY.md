# Privacy Policy

Rivers IOC does not persist user data. To perform a query, it transmits the configured access token
and the IP address supplied by the user to Chaitin Rivers (`intelligence.rivers.chaitin.cn`). Chaitin
Rivers processes these values according to its service terms and privacy policy. The plugin does not
send them to any other service and does not include tokens in error messages or logs.

# 隐私政策

Rivers IOC 不会持久化用户数据。执行查询时，插件会将配置的访问令牌和用户提供的 IP 地址
发送至长亭百川云（`intelligence.rivers.chaitin.cn`），百川云将依据其服务条款和隐私政策处理
这些数据。插件不会将其发送至其他服务，也不会在错误信息或日志中输出令牌。
